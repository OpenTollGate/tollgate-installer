Narration (I1+tail)

Both manual paths start from vanilla OpenWrt with an internet uplink. First pick the profile for your device from the official index — never from memory. Download the image and its checksum, and verify it before you flash. A wrong image is a brick. Then sysupgrade with dash-n for a clean slate… Now the manual install. Both lanes are the same shape: resolve the release, fetch the package, verify it, then install it by path — apk on 25.12, opkg on 24.10. …the post-install restarts networking and moves the wired LAN ports onto the private bridge, so your SSH session drops; reconnect at the new address. This is the TollGate captive portal… the Wallet holds what the router earned… and with Drain, the owner withdraws the whole balance as a Cashu token.
